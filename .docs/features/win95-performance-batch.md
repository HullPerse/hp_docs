## Win95 preset

Idea: add Windows 95 as a fourth DESIGN.md preset, portable recipe only.
Comment: iluhaAnime ships a full Win95 system; only the generic chrome ports (bevel vocabulary, face/field tokens, progress/titlebar/tabs/menu recipes, motion and focus). Domain tokens (torrent/graph/fav), theme content, and OS integration stay behind.

## PERFORMANCE.md

Idea: new optional template file with the iluhaAnime benchmark contract.
Comment: eight sections (commands, gates, what-to-bench, evidence, bench-first rejections, fix hierarchy, scale table, journal). Created when perf-sensitive paths exist or the user asks; otherwise DEVELOPMENT.md plus TESTING.md carry the rule.
Pros: budgets, minDelta, checksum, N/A domains, IPC chatter and memory scale benches, and rejection logs stop unmeasured claims.
Cons: one more generated file for hp-docs-update to migrate; small projects may never create it.
