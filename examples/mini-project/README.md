# Mini Project Example

Компактный пример заполненных доков на вымышленном микро-проекте `todo-cli` (TypeScript + Bun, CLI без UI). Показывает, как выглядят шаблоны после инициализации: плейсхолдеры заменены реальными данными, DESIGN.md удалён за ненадобностью (не-UI проект), DECISIONS.md содержит живые записи.

Файлы:

- `AGENTS.md` - точка входа агента
- `.docs/AGENT_PROMPT.md` - контракт сессии
- `.docs/DEVELOPMENT.md` - конвенции и зафиксированные решения
- `.docs/DECISIONS.md` - журнал решений

Это пример, а не рабочий набор: не копируй его в проект напрямую, генерируй через flow first-run скилла `ai-docs`.
