# Mini Project Example

A compact example of filled docs on a fictional micro-project `todo-cli` (TypeScript + Bun, CLI without UI). It shows what the templates look like after initialization: placeholders replaced with real data, DESIGN.md dropped as unnecessary for a non-UI project, and DECISIONS.md carrying live entries.

Files:

- `AGENTS.md` - agent entry point
- `.docs/AGENT_PROMPT.md` - session contract
- `.docs/DEVELOPMENT.md` - conventions and fixed decisions
- `.docs/DECISIONS.md` - decision journal

This is an example, not a working set: never copy it into a project directly; generate docs through the first-run flow of the `hp-docs` skill.
